# Background check

Микросервис для задачи «Фон и посторонние предметы». Принимает фото товара, находит главный объект (флакон, коробку), вырезает его и проверяет, что осталось вокруг:

| Вердикт | Что значит |
|---|---|
| `clean` | фон однотонный (любого цвета), посторонних предметов нет |
| `noisy` | фон неоднородный: текстура, градиент, интерьер, но отдельных предметов не найдено |
| `objects` | кроме главного объекта в кадре есть другие предметы |
| `no_object` | главный объект не найден |

## Как работает

1. **Сегментация.** Нейросеть [rembg](https://github.com/danielgatis/rembg) (`isnet-general-use`, ONNX, CPU) строит маску объектов. Самое крупное пятно маски и пятна размером не меньше 10% от него (флакон + своя коробка) — это товар. Остальные заметные пятна — посторонние предметы (`source: "mask"`).
2. **Фон** — всё вне маски, с отступом от краёв объекта. Под цвет фона подгоняется плавная поверхность (квадратичная по координатам, в пространстве Lab), поэтому и однотонный фон, и мягкий градиент считаются ровными. По фону считаются:
   - `uniformity` — доля пикселей, близких к этой поверхности (ΔE < 10);
   - `edge_density` — доля пикселей на границах (детектор Canny), показывает текстуру и мелкие детали.
3. **Пятна на фоне.** Участки, сильно отличающиеся от фона (ΔE > 25) и достаточно крупные, тоже считаются посторонними предметами (`source: "background"`). Пятна, касающиеся товара, не считаются: обычно это тени, отражения или кусок товара, который не попал в маску.
4. **Вердикт:** есть предметы → `objects`; `uniformity ≥ 0.95` и `edge_density ≤ 0.02` → `clean`; иначе `noisy`.

Анализ идёт на уменьшенной копии (длинная сторона 512 px), координаты в ответе пересчитаны в пиксели исходного фото.

## Запуск

```bash
docker build -t carat-background-check background-check
docker run --rm -p 8000:8000 carat-background-check
```

Интерактивная документация (можно загрузить фото прямо в браузере): http://localhost:8000/docs

Без Docker (нужен [uv](https://docs.astral.sh/uv/)):

```bash
cd background-check
uv sync
uv run uvicorn app:app --port 8000
```

Зависимости — в `pyproject.toml` и `uv.lock`, добавлять через `uv add <пакет>`.

### Модель

Веса в репозиторий не коммитятся. `rembg` скачивает модель сам при первом запуске:

| Модель | Файл | Источник | Куда кладётся |
|---|---|---|---|
| `isnet-general-use` | `isnet-general-use.onnx` (~170 МБ) | релизы [danielgatis/rembg](https://github.com/danielgatis/rembg/releases/download/v0.0.0/isnet-general-use.onnx) | `$U2NET_HOME` (в образе `/app/models`, локально `~/.u2net`) |

В Docker модель скачивается при сборке образа, поэтому контейнеру интернет не нужен.

## API

### `POST /analyze`

Поле формы `file` — изображение (JPEG, PNG, WebP).

```bash
curl -F "file=@photo.jpg" http://localhost:8000/analyze
```

```json
{
  "verdict": "objects",
  "ok": false,
  "width": 1200,
  "height": 1200,
  "main_object": {"bbox": [402, 151, 398, 902], "area_share": 0.1987},
  "background": {"color": "#f4f2ef", "uniformity": 0.9312, "edge_density": 0.0154},
  "foreign_objects": [
    {"bbox": [820, 640, 260, 300], "area_share": 0.0402, "source": "mask"}
  ]
}
```

| Поле | Описание |
|---|---|
| `verdict` | `clean` / `noisy` / `objects` / `no_object` |
| `ok` | `true` только для `clean` |
| `main_object.bbox` | рамка главного объекта: `x, y, ширина, высота` в пикселях исходного фото |
| `*.area_share` | доля площади кадра |
| `background.color` | основной цвет фона |
| `background.uniformity` | доля фона, близкая к основному цвету (0–1) |
| `background.edge_density` | насыщенность фона деталями (0–1) |
| `foreign_objects[].source` | `mask` — отдельный объект по сегментации, `background` — пятно другого цвета на фоне |

### `POST /cutout`

Возвращает PNG с главным объектом на прозрачном фоне, обрезанный по рамке объекта. Если объект не найден — `422`.

```bash
curl -F "file=@photo.jpg" http://localhost:8000/cutout -o cutout.png
```

### `GET /health`

`{"status": "ok", "model": "isnet-general-use"}`

### Ошибки

| Код | Когда |
|---|---|
| `415` | файл не является изображением |
| `422` | нет поля `file` или (для `/cutout`) не найден объект |

## Проверка на датасете

Случайные 200 фото из `dataset.jsonl` (задача #19): 100 с типом `studio` и 100 с типом `casual`, только не-негативы.

| Тип в датасете | `clean` | `noisy` | `objects` |
|---|---|---|---|
| `studio` | 92 | 5 | 3 |
| `casual` | 37 | 33 | 30 |

- На студийной съёмке 92% получают `clean`. Из оставшихся: белый фон с мягкой тенью, отдельно лежащая крышка.
- `casual` в датасете значит «бытовая съёмка», а не «грязный фон». Большая часть из 37 `clean` при просмотре — флакон на однотонной стене, то есть ответ верный.
- Скорость: около 1.7 с на фото на CPU (ноутбук, Docker Desktop).

## Ограничения

- **Предмет вплотную к товару** (рука, держащая флакон, камни-подставка, свеча рядом с коробкой) нейросеть склеивает с товаром в одно пятно, и он не считается посторонним. Это лечится детектором с текстовыми запросами (YOLO-World: `hand`, `person`, `card`, `flower`…), но он требует PyTorch и увеличит образ.
- Отдельно лежащие части товара меньше 10% от него (крышка, пробник) считаются посторонними предметами.
- Тёмная однородная текстура (тёмное дерево, ткань) может пройти как `clean`: она малоконтрастная.

## Настройка

Модель задаётся `ENV MODEL` в Dockerfile и скачивается при сборке: например `u2net` — быстрее, `birefnet-general` — точнее, но тяжелее. Пороги вердикта — константы в начале `app.py`.
