# Carat

> [!NOTE]
> Carat is a fork of [Cogniflex](https://github.com/duckysmacky/cogniflex). It uses that project as its base and shares the same owner and contributors, but will progress in a different direction.

## About

Carat is an open platform designed to help people automatically identify and warn about AI-generated content on the internet. It analyzes digital content and estimates the probability that it was generated by artificial intelligence.

The system focuses on **two main types of content**:

- Text - articles, posts, comments, and other written material
- Images - pictures that may have been generated using diffusion models or other AI systems

Instead of making absolute claims, Carat provides probabilistic assessments, helping users interpret information more critically.

## Features

### Manual analysis tools

Users can paste text, images and videos into the analysis interfaces on our website to get a probabilistic assessment.

### Multi-method detection

Instead of relying on a single model, Carat combines multiple approaches, including:

- machine learning models
- statistical analysis
- structural content patterns
- heuristic algorithms

This hybrid approach improves reliability and flexibility.
