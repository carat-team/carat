# Требования заказчика (Честный Знак)

Источник истины для списка проверок Carat. Только категория «Парфюмерия».
Актуально на 2026-10-30. Подтверждено стороной ЧЗ, если не указано иное.

## Требования

| № | Требование | Доля реальных ошибок в данных ЧЗ | Taiga | Статус кода |
|---|---|---|---|---|
| R1 | Проверяется только категория «Парфюмерия» | - | - | границы категории задаются на входе |
| R2 | Бренд в атрибуте не совпадает с брендом в наименовании | 79,1% | #28 | кода нет |
| R3 | Наименование не соответствует типу парфюмерной продукции | 15,6% | #29 | PR #19 открыт |
| R4 | Значение бренда «Без товарного знака» недопустимо | 2,99% | #31 | - |
| R5 | Объём в атрибуте не совпадает с объёмом в наименовании | ~2,3% | #30 | PR #16 открыт |
| R6 | Наименование из одного слова или только из типа отклоняется | ~0% | #32 | - |
| R7 | Код ТН ВЭД не соответствует типу парфюмерной продукции -> отклонить (Марат, 12 октября) | не оценено | нет истории | - |
| R8 | Идентификаторы и ограничения полей по ППР № 1957 (Attributes Model.xlsx) | - | - | - |

## Как пользоваться

- Новая проверка в `algorithms/` ссылается на номер требования в описании PR.
- Если номера нет, проверка помечается «inferred» в docstring.
- Изменение этого файла согласуется с владельцем проекта.
